About This Project

Dataset

Built on the FER-2013 dataset introduced at ICML 2013 — containing ~35,000 grayscale 48×48 pixel facial images across 7 emotion categories.

Model Architecture

CNN + BatchNormalization + Dropout

  • 3 convolutional blocks (64 → 128 → 256 filters)
  • BatchNorm after each Conv2D layer
  • Dropout (0.25 / 0.5) for regularisation
  • Dense head: 512 → 256 → 7 (softmax)
